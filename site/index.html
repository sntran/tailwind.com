The changes of Tailwind CSS, release by release

        

          The Rust compiler has a switch for each change of behavior in a release of Tailwind CSS, so it can compile as each
          older version. Each recorded case shows one change: open it to compare the version before the change with the
          version of the change. The method and the full list are in
          docs/SWITCHES.md.
